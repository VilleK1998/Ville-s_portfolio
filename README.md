# Customer Analysis Dashboard

### Project Overview

This project presents an interactive Tableau dashboard built as part of a Business Intelligence: Applications and Projects 813320A-3005 course final project in the University of Oulu Business Analytics Master's degree programme. The dashboard offers in-depth analysis of customer purchasing behavior based on the "Ecommerce Consumer Behavior Analysis Data" sourced from Kaggle. It is designed to mimic a dashboard that could help businesses uncover insights about high-value customer segments, brand loyalty, discount sensitivity, and seasonal spending patterns.

The aim of the course project was to design and develop a dashboard with the appropriate
visualizations, using Tableau, for solving a business problem and supporting decisionmaking. Using Tableau, we were meant to conduct data storytelling to visualize the data and develop an
interactive dashboard. We were expected to select and utilize a majority of the concepts and techniques
covered in the course and be able to elaborately explain and support the choices, which we managed to do.

### Data Source

Consumer Behavior Data: The primary dataset used for this analysis and interactive dashboard is the "Ecommerce_Consumer_Behavior_Analysis_Data.csv", containing comprehensive collection of consumer behavior data.

Link for the dataset: [Ecommerce Consumer Behavior Analysis Data](https://www.kaggle.com/datasets/salahuddinahmedshuvo/ecommerce-consumer-behavior-analysis-data)

### Tools

- Tableau

### Key Features and Data Preparation

Data Cleaning & Transformation: Cleaned currency fields, grouped continuous variables like age, and simplified complex gender values.

Interactive Filters: Users can filter all visualizations by demographic variables like Age Group, Gender, Income Level, Marital Status, and Education Level.

#### Visualizations Included:

Bar chart of average purchase amount by demographic group.

Discount usage rates across customer segments.

Pie chart of purchase channel preferences (online, in-store, mixed).

Brand loyalty vs. spending analysis with regression insights.

Line chart showing monthly spending trends.

### Project Objective
To explore and visualize e-commerce customer data to:

- Identify which demographic groups spend the most.
- Analyze discount usage and brand loyalty trends.
- Understand shopping channel preferences.
- Track changes in spending behavior over time.

### Key Results and Findings
- High-income, older customers identifying outside traditional gender categories spend the most.
- Discount sensitivity varies subtly but shows younger segments are more promotion-driven.
- Brand loyalty does not necessarily correlate with higher spending.
- Online shopping dominates among younger users; hybrid behavior is also prominent.
- Clear seasonal trends with peaks in February and dips in May and October.
